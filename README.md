# Трекер посилок для старих iPhone

Це окрема статична вебсторінка для відстеження накладних Нової пошти. Вона не є офіційним застосунком перевізника і не потребує встановлення IPA.

## Публікація

GitHub Actions публікує `index.html` у GitHub Pages після push до гілки `main`. Для першого запуску в Settings → Pages виберіть Source: GitHub Actions, якщо це потрібно для репозиторію.

## Використання

На iPhone 4s відкрийте HTTPS-адресу сайту в Safari та виберіть «На Початковий екран». Локально сторінка відкриється, але для запитів до API потрібна HTTPS-адреса.

## Нативна iOS-оболонка

Каталог `NativeApp` містить просту оболонку для iOS 9, яка відкриває опублікований трекер у WKWebView. Workflow `Build iPhone app` намагається зібрати armv7 IPA для iPhone 4s. API-ключ у застосунок не вшивається — його вводять у самому трекері.

## Підключення

1. Вставте власний API-ключ Нової пошти й натисніть «Зберегти ключ».
2. Додайте номер накладної.
3. Натискайте «Оновити» для однієї посилки або «Оновити всі».

Ключ і список накладних зберігаються у локальному сховищі Safari. Запити надсилаються напряму на API Нової пошти; сервер-посередник не використовується.
